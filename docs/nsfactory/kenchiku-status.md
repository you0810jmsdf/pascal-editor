## 仕様からの変更・補足

- **耐力壁の仕様の入力場所**: 壁インスペクタ（kind 固有パネル）への欄追加は見送り、建築法規パネルの「耐力壁」タブに「選択中の壁に適用」「階の全壁に適用」と壁ごとのセレクトを置いた。壁の custom panel への差し込みは別作業。
- **3D の耐力壁表示（E-006）**: 2D の平面図オーバーレイのみ。3D 側は未実装（理由: 壁上面への帯描画は viewer 側の新しい描画物になり、本スライスの範囲を超える）。
- **屋根が無いシーン**: 計算を止めず、4寸切妻・軒の出0.45m・短辺に棟を仮定して注記する（§6.1(7) の上書き優先はそのまま）。
- **建物の向き**: 壁の主方向（長さ重み・90°周期）を求めて建物座標を回し、斜めに描かれた建物でも X/Y 方向を集計する（`axisRotation`）。敷地と真北も同じ座標へ移す。
- **仕様が未入力のとき**: 外壁＝サイディング、屋根＝スレート、木材＝すぎ無等級で計算し、注記に明示（止めない）。
- **仕様書の誤りを訂正**: §11 四分割の例（帯は 20㎡）、§4.3 金物「ぬ」（15kN×2＝30kN）。
- **検査ゲート**: リポジトリ全体の `bun run check`（Biome）は作業前から既存コード（packages/viewer・apps/editor）の指摘で失敗している。触ったパスの指摘ゼロを条件にした。`bun test`・`check-types`・`build`・`build:static` は通過。
- **dist の罠**: ワークスペースの参照は `dist/` 経由。`packages/kenchiku`・`packages/core` の公開 API を変えたら `bun run build` してからテスト・静的ビルド。
- **Git Bash の罠**: `--base /pascal-editor` は Git Bash が Windows パスに変換するため `MSYS_NO_PATHCONV=1` を付ける。
